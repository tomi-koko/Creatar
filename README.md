# Creatar

Creatar is a front-end web application designed to help users improve their creative ability and organize their creative process through structured planning and visual thinking.

Rather than focusing on output alone, Creatar emphasizes **how ideas are formed, connected, and evolved over time**.

---

## What is Creatar?

Creatar provides a lightweight environment for:

- Structuring creative ideas
- Planning creative paths and iterations
- Exploring relationships between thoughts, drafts, and concepts
- Supporting long-term creative growth rather than one-off production

It is intended for writers, designers, developers, and anyone engaged in continuous creative work.

---

## Key Concepts

- **Creation as a process**, not a single action
- **Planning without rigidity**
- **Visual and structural thinking** instead of linear notes
- **Front-end first**, with no mandatory backend

---

## Current Status

Creatar is currently an experimental project and is under active development.

The initial version focuses on front-end interaction and conceptual modeling.  
Future iterations may explore persistence, data export, or extended creative workflows.

---

## First Release

- Initial public release on CodePen  
- This repository serves as the long-term source and documentation for the project

---

## Tech Stack

- HTML / CSS / JavaScript
- SVG / Canvas-based visualization
- No framework dependency (subject to change)

---

## Philosophy

Creatar is not a productivity tool in the traditional sense.  
It does not aim to optimize speed or output.

Instead, it is built to support **clarity, continuity, and reflection** in creative work.
